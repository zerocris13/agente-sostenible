# Evaluador de Bonos Sostenibles

Interfaz de demostracion para consultar clasificaciones preliminares de proyectos de inversion publica segun el Marco del Bono Sostenible del Peru 2021.

Desarrollado en el contexto de un proyecto academico grupal.

Esta version presenta resultados previamente guardados. No ejecuta el backend LangGraph ni consume la API de OpenAI.
